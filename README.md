# MML-Packages

Domain packages for MinimalMathLibrary: Fourier, optimization, PDE, statistics, and symbolic mathematics. The 0.1 prerelease provides prebuilt C++20 static libraries and matching headers for Windows x64, Linux x86-64, and macOS arm64.

See the [binary installation guide](docs/Binary_Release.md) for supported toolchains, checksum verification, CMake targets, provenance, and license notices. Downloads and release-specific limitations are listed on the [prerelease page](https://github.com/zvanjak/MML-Packages/releases/tag/v0.1.0-rc.5).
